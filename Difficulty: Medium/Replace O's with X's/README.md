<p><span style="font-size: 18px;">A 'O' (or a set of 'O') is considered to be surrounded by 'X' if there are 'X' at locations just below, just above, just left and just right of it.</span></p>

<pre><span style="font-size: 18px;"><strong>Input:</strong> grid[][] = [['X', 'O', 'X', 'X'], ['X', 'O', 'X', 'X'], ['X', 'O', 'O', 'X'], ['X', 'O', 'X', 'X'], ['X', 'X', 'O', 'O']]
<strong>Output:</strong> <br><img src="https://media.geeksforgeeks.org/img-practice/prod/addEditProblem/932637/Web/Other/blobid2_1785761833.png" width="175" height="211"><br><strong>Explanation:</strong> There's no 'O' that's surround by 'X'.</span></pre>
